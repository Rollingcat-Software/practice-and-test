WARNING: CRITICAL FINDINGS:
  [T2_CORRECT_FAKE] CRITICAL — correct-action fake bypass accepted (no server-side frame check)

Root cause: liveness confirmation is based only on client-supplied
confidence values + timestamp ordering. The server has no frame-level
image analysis to verify actions were actually performed.
The spot_frame check (server-side frame analysis) exists in code but
the MiniFASNet detector is broken (BUG-02), so it always passes.

Recommended fix:
  1. Fix MiniFASNet model path (BUG-02) to enable server-side spot check.
  2. Make spot_frames mandatory (not optional) in the verify request.
  3. Reject any verify request without valid spot_frames.
